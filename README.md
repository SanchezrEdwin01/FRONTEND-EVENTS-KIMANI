# Events
A modern event management application built with React, Vite, TypeScript and Tailwind for Kimani Life.

## 🚀 Features

- Modern React application with TypeScript support
- Styled with Tailwind CSS and Styled Components
- Google Maps integration
- Date picker functionality
- Responsive design
- React Query for data fetching
- Comprehensive testing setup

## 📋 Prerequisites

- Node.js (LTS version recommended)
- pnpm package manager

## 🛠️ Installation

1. Install pnpm if you haven't already:
   ```bash
   npm install -g pnpm
   ```

2. Clone the repository:
   ```bash
   git clone https://github.com/KimaniLife/KIMANI-events-v2.git
   cd KIMANI-events-v2
   ```

3. Install dependencies:
   ```bash
   pnpm install
   ```

## 🚀 Development

To start the development server:

```bash
pnpm dev
```

The application will be available at `http://localhost:5173`

## 📦 Available Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm serve` - Preview production build
- `pnpm test` - Run tests
- `pnpm lint:eslint` - Run ESLint
- `pnpm fix:eslint` - Fix ESLint issues
- `pnpm lint:stylelint` - Run Stylelint
- `pnpm fix:stylelint` - Fix Stylelint issues

## 🧪 Testing

The project uses Jest and React Testing Library for testing:

```bash
pnpm test
```
